# Сопроводительное · ГРАН · Оператор по проверке данных (фотоаудитор)

**Компания / проект:** ГРАН (#РаботаГран)  
**Роль:** оператор по проверке данных / фотоаудитор (выкладка товаров на фото)  
**Формат:** смены 5/2 или 2/2 · день / ночь · обучение правилам платформы  
**Оплата:** фикс + премии за скорость и качество (цифра в вакансии не указана)  
**Оценка совпадения:** ~80%

| Критерий | Комментарий |
|----------|-------------|
| Идеальная внимательность к деталям на фото | ✅ дизайн-глаз + QC |
| Грамотная обратная связь в чате | ✅ |
| Монотонный поток, концентрация | ✅ |
| Подтвердить / отклонить + инструкция «что исправить» | ✅ Pass/Fail + следующий шаг |
| Контроль сроков на переделку | ✅ |
| Входящие + исходящие звонки для уточнений | ⚠️ голос наращу; не продажи |
| Опыт не главное — качества | ✅ |

## Текст сопроводительного

```
Здравствуйте, команда ГРАН!

Меня зовут Альбина Акбарова (на проектах подписываюсь как Аля). Откликаюсь на вакансию оператора по проверке данных (фотоаудитор).

Почему роль:
Мне близка позиция «первый контроль качества»: внимательно разобрать фото выкладки, решить Pass/Fail по правилам и дать участнику понятную инструкцию, что исправить — без воды и без грубости. Комфортна монотонная, но ответственная работа на потоке: концентрация, единые критерии, сроки на переделку. Опыт мест работы для вас не главный — как раз опираюсь на внимательность, грамотность и усидчивость.

Что сделаю:

— Проверю фотозадания на корректность выкладки: замечу смещения, общий/крупный план, перепутанные позиции и другие отклонения по вашим правилам.
— Подтвержу выполнение в системе или отклоню с чёткой обратной связью («поменяйте местами…», «нужен общий план…»).
— Отслежу срок на исправление и закрою задание, если корректное фото не пришло.
— Приму входящие обращения и при необходимости сделаю исходящий звонок для уточнения деталей — спокойно и по регламенту (письменный канал у меня сильнее; голос наращу на обучении).
— Пройду полное погружение в правила платформы и типы заданий до выхода на поток.

Бэкграунд, который помогает: дизайн (насмотренность и деталь на изображении) + привычка проверять по критериям «сценарий → факт → вердикт». Ноутбук и стабильный интернет есть (Лысьва, Пермский край).

Условия: график 5/2 или 2/2, дневные или ночные смены — обсуждаю; фикс + премии за скорость и качество — ок. Интересен рост до супервайзера / тренера при стабильном качестве проверок.
```
