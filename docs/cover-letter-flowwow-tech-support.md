## Текст сопроводительного

```
Здравствуйте, команда Flowwow!

Меня зовут Альбина Акбарова (на проектах подписываюсь как Аля). Откликаюсь на вакансию специалиста технической поддержки.

Почему Flowwow:
Интересна поддержка «изнутри»: не только чинить тикеты, а участвовать в автоматизациях и интеграциях внутренних сервисов — чтобы процессы работали стабильно и их можно было развивать. Близок формат: скрипт/связка → мониторинг → доработка → понятная документация для команды.

Что умею по ожиданиям:

— Автоматизация процессов: собираю рабочие контуры «ручной шаг → сервис/скрипт → результат». Пример: Telegram → Google Sheets (lead capture); пайплайны данных на Python с LLM-шагом → Excel.
  Портфолио: https://portfolio-resume-alya-akbarova.vercel.app/

— Python и JavaScript/TypeScript: скрипты, небольшие сервисы, правки и отладка. Читаю и исправляю код, в том числе сгенерированный AI.

— AI / vibe-coding: Cursor, OpenCode, Gemini — основной способ быстро собрать MVP и внутренние инструменты до рабочего состояния, с обязательной самопроверкой.
  NOVA (React/TS + AI-ассистент): https://nova-light-app.vercel.app/
  CRM Lead Card: https://alya-crm-lead-card.vercel.app/

— API и интеграции: REST, JSON, webhooks; подключение внешних сервисов и обмен данными между системами.

— Сопровождение и качество: бэкграунд QA — мониторю поведение, ищу сбои, фиксирую воспроизводимо, довожу до стабильного результата. Задачи руководителя закрываю в срок.

Плюсы из вакансии:
HTML/CSS — да; Google Docs/Sheets — уверенно; документирование автоматизаций — пишу гайды «как пользоваться»; Jira/Confluence — быстро освою на вашем процессе (сейчас чаще веду статусы в таблицах).

Формат: удалённо — подходит. Готова к собеседованию и тестовому на небольшую автоматизацию/интеграцию под ваш стек.

Резюме: https://portfolio-resume-alya-akbarova.vercel.app/resume-ai.pdf
GitHub: https://github.com/PilotAlya
Telegram: @Albinaa_Akbarova · Email: pilotalya@a-akbarova.ru

С уважением,
Альбина Акбарова
```
