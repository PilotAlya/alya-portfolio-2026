### Текст для отправки

```
Обычно работаю с малым и средним объёмом — не Big Data, а прикладные таблицы, где важна точность сверки и бизнес-логика.

По масштабу:
— B2B-кейс: 6 связанных CSV-таблиц (клиенты, контракты, отгрузки, статусы) — порядка сотен–тысяч строк суммарно. Нашла 3 системные ошибки в расчёте оттока, пересчитала Churn Rate (72,7% → 63,6%), собрала дашборд для руководства.
— Ритейл / Legacy: сверка 100+ позиций номенклатуры и цен (раньше вручную — часами; автоматизировала до секунд).
— Операционные таблицы: Google Sheets для метрик, багов, статусов задач — обычно десятки–сотни строк, но с чёткой структурой и приоритетами.
— Парсинг: Price Checker — цены с маркетплейсов для контроля маржи (динамические данные, регулярное обновление).

Инструменты:
— Google Sheets — быстрая аналитика, статусы, сводки, совместная работа.
— Python + Pandas — аудит CSV, проверка расчётов, склейка таблиц, валидация данных (ETL-ошибки, дубли, «переименованные» сущности).
— Cursor + Gemini — ускоряю гипотезы и пишу/правлю скрипты, но финальную логику и цифры всегда проверяю руками.
— Chart.js + Vercel — наглядные дашборды для руководства (Executive Dashboard).
— Excel — как источник/формат обмена; стараюсь выносить повторяющуюся сверку в скрипты.

Big Data (миллионы строк, DWH, SQL на уровне аналитика) — пока не мой текущий уровень, но базовую работу с таблицами, метриками и автоматизацией рутины закрываю уверенно. Для задач вроде аналитики соцсетей, трафика и продаж менеджеров — привычный формат: несколько источников → сводная таблица → выводы и гипотезы.
```
