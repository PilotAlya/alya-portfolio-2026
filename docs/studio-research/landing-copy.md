## 1) Название проекта
Автоматизация поиска дизайн-студий с AI-фильтрацией

## 2) Короткий подзаголовок (1 строка)

## 3) Карточка проекта (коротко)
**Роль:** идея, логика, разработка, тестирование на реальных городах  
**Стек:** Python, Requests, BeautifulSoup, Pandas, OpenPyXL, Gemini API  
**Результат:** готовый список дизайн-студий-команд в Excel с кликабельными ссылками

## 4) Полный кейс (для страницы проекта)

### Задача
Нужно было быстро собирать базу дизайн-студий по городу и отделять реальные команды/бюро от одиночек-фрилансеров. Вручную это долго: поиск, заход на сайт, чтение раздела «О нас», проверка команды.

### Решение
Я разработала локальный Python-скрипт, который повторяет этот процесс автоматически:

1. Ищет компании по запросу (например, «студия дизайна интерьера Пермь»)
2. Отфильтровывает агрегаторы (Avito, 2GIS, Houzz и т.п.)
3. Парсит тексты сайтов, включая страницы «О нас» и «Команда»
4. Передаёт текст в LLM (Gemini), чтобы определить: это команда или одиночка
5. Сохраняет только релевантные студии в CSV/Excel с кликабельными ссылками

### Что сделано мной
- Спроектировала логику пайплайна end-to-end
- Реализовала модульный код с обработкой ошибок (таймауты, 403/404)
- Подключила AI-анализ через API и вынесла ключи в `.env`
- Протестировала на Екатеринбурге и Перми
- Добавила выгрузку в Excel с рабочими гиперссылками

### Стек
Python 3 · Requests · BeautifulSoup · Pandas · OpenPyXL · Gemini API · python-dotenv · DDGS (веб-поиск)

### Результат
- Автоматический сбор и фильтрация студий по городу
- На тестовых запусках получены релевантные команды для Екатеринбурга и Перми
- Результат сразу готов к работе в Excel (название, сайт, основатель, доказательство)

### Зачем это бизнесу
Экономит время на ручном ресёрче и помогает сразу работать с более качественной базой потенциальных партнёров или клиентов.
