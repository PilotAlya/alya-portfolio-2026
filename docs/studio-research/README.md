# Материалы для портфолио

Всё готово к вставке на лендинг. Секреты и `.env` сюда не входят.

## Что внутри

| Файл | Для чего |
|------|----------|
| `landing-copy.md` | Готовые тексты: название, описание, кейс, буллеты, English |
| `case.html` | Красивая демо-страница кейса — откройте в браузере и сделайте скрин |
| `demo-results.xlsx` | Таблица с кликабельными ссылками для скачивания / приложения |
| `demo-results.csv` | То же в CSV |

## Как использовать за 5 минут

1. Откройте `landing-copy.md` и скопируйте блоки на лендинг.
2. Откройте `case.html` в Chrome/Edge → сделайте скриншот блока с таблицей.
3. При желании приложите `demo-results.xlsx` как «скачать пример результата».
4. Код на GitHub выкладывайте отдельно и только без `.env`.

## Что писать в кнопках

- **Смотреть кейс** → якорь на описание / `case.html`
- **Скачать демо** → `demo-results.xlsx`
- **Код** → ссылка на репозиторий (если будет)
