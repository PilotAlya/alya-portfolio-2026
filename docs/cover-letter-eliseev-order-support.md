# Сопроводительное · ИП Елисеев · Специалист по сопровождению интернет-заказов

**Наниматель:** ИП Елисеев Максим Анатольевич  
**Роль:** специалист по сопровождению интернет-заказов (удалённо)  
**Формат:** полная занятость · удалённо · график компании · ТК / ГПХ / самозанятость  
**Оплата:** фикс 50 000 ₽ · средний совокупный от 87 500 ₽ + премии  
**Оценка совпадения:** ~57% · **условие:** без обязательных тёплых/холодных звонков ([RULE-no-calls](./RULE-no-calls.md))

| Критерий | Комментарий |
|----------|-------------|
| Сопровождение заказов, консультации | ✅ если чат/почта |
| Возражения, «помочь принять решение» | ⚠️ мягкий дожим; ок в переписке |
| CRM | ⚠️ освою |
| Опыт КЦ / продаж (плюс в вакансии) | ❌ нет; плюс намекает, что голос возможен |
| Канал связи в тексте не указан | ⚠️ **уточнить до старта**; если ядро = звонки → skip |
| Фикс 50к + до ~87,5к | ✅ уточнить, как считается «средний» |

> **Правило:** если на созвоне выяснится обязательная телефония / тёплые звонки — **отказ**. Отклик имеет смысл только при чате/почте/мессенджере.

Мне близко сопровождение уже оформленных заказов: ответить по статусу, оформлению и получению, спокойно закрыть вопрос клиента и вести CRM — без холодного поиска клиентов. Удалёнку рассматриваю как основное место, готова к полной занятости, обучению с наставником и долгосрочному формату.
