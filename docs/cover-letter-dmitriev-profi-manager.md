**Наниматель:** Дмитриев Андрей Викторович  
**Роль:** менеджер по работе с заявками Профи.ру (мессенджер → диагностика → отчёт)  
**Формат:** удалённо · на связи 10:00–22:00 МСК · обучение 1 ч/нед  
**Оплата:** 2 нед. 5 000 ₽ + 500 ₽/диагностика → далее 1 500–4 000 ₽/нед + 500 ₽/диагностика · выплата раз в неделю  
**Оценка совпадения:** ~58% (задачи ок; **слабые условия** по деньгам и длине смены)

| Критерий | Комментарий |
|----------|-------------|
| Ответы на заявки в мессенджере | ✅ грамотная переписка, спокойный тон |
| Подбор слота диагностики, передача в чат | ✅ аккуратность, статусы |
| Ежедневный отчёт | ✅ |
| Планерки / обучение / рост | ✅ |
| Пунктуальность, вопросы без страха | ✅ |
| На связи 10:00–22:00 МСК | ⚠️ 12 часов — явно подтвердить, если реально тянешь |
| Опыт Профи.ру / EdTech-продаж | ⚠️ нет штатного — быстрый вход по скриптам |
| Вилка оплаты | ⚠️ низкая относительно целевой; отклик только если ок как вход |

> **Вердикт:** задачи — «обработка заявок + дисциплина». Имеет смысл, если готова к длинному онлайну и скромному старту ради роста. Иначе лучше не тратить слот.
