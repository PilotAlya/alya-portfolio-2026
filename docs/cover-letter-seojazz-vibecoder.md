### Какие базовые SEO-требования учитываю при создании сайта

Не выдаю себя за SEO-специалиста агентства — держу базу, которую можно сдать в работу оптимизатору:

— один H1, иерархия H2–H3 без скачков;
— title и description по смыслу страницы (не «рыба»);
— семантическая вёрстка, понятные URL, alt у изображений;
— индексация: не закрыть служебное noindex по ошибке; человекочитаемые ссылки;
— скорость и мобильная вёрстка (адаптив, читаемый текст без горизонтального скролла);
— контент отвечает на запрос/интент страницы, без скрытого текста и дублей H1.

Спорные SEO-решения (кластер, перелинковка, ТЗ по ключам) — сверяю с вашим SEO, а не «на глаз».

Плюсы: UX-проверки (NOVA), GitHub, простые API/автоматизации. Генерация изображений через AI — по задаче, не основной навык; подключу ваш пайплайн.
