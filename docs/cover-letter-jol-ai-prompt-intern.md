**Наниматель:** Болатбекуулу Тилек · JOL AI (B2B no-code, AI-сотрудники в WhatsApp / Instagram / Telegram)  
**Роль:** стажёр AI / Prompt-инженер → перспектива штата  
**Оценка совпадения:** ~78%

| Критерий | Комментарий |
|----------|-------------|
| ChatGPT / Claude / Gemini, понимание «почему так ответила модель» | ✅ ChatGPT/Gemini daily; Claude по задаче |
| Грамотный русский для клиентских текстов | ✅ |
| Разложить продажу на шаги и сценарии | ✅ логика воронки/статусов; скрипты продаж наращу |
| Довести задачу без напоминаний | ✅ |
| Промпты, тон, персона, логика диалога | ✅ сильная сторона |
| Базы знаний (прайсы, инструкции, сайты) | ✅ структурирование, ресерч → таблица/гайд |

| Интеграции: мессенджеры, Calendar, CRM | ⚠️ Telegram→Sheets, Lead Card/NOVA; WhatsApp/IG агенты в проде — на стажировке |

| Переход в штат по итогам | ✅ целевой интерес |

## Текст сопроводительного

```
Здравствуйте, Тилек / команда JOL AI!

Меня зовут Альбина Акбарова (на проектах подписываюсь как Аля). Откликаюсь на стажировку AI-инженера (Prompt Engineer) с перспективой перехода в штат.

Почему JOL AI:
Близок продукт «AI-сотрудник для продаж в мессенджерах»: не просто чат-ответ, а квалификация лида, сценарий сделки и связка с CRM. Хочу настраивать агентов под бизнес клиента — персона, тон, логика диалога — тестировать слабые места и доводить до рабочего поведения вместе с Customer Success. Стажировка с шансом в штат — именно тот формат роста, который мне нужен.

Что уже умею (опыт в вакансии не требуется — но база есть):

— Промпты и модели: ежедневно ChatGPT / Gemini, Claude — по задаче. Не принимаю первый ответ: задаю роль и ограничения, критерии «хорошего ответа», итерирую, пока тон и логика не стабильны.
— Сценарии: умею разложить процесс на шаги (вход → уточнение потребности → следующий шаг / эскалация) и оформить это текстом, который читает клиент — грамотно и без воды.
— Базы знаний: собираю и структурирую материалы (сайты, инструкции, таблицы) так, чтобы ими можно было пользоваться в работе агента/команды. Пример: ресерч → классификация → Excel — https://portfolio-resume-alya-akbarova.vercel.app/#case-studios
— Тестирование: QA-привычка «сценарий → факт → вердикт»; ловлю дыры в диалоге и краевые случаи. На своём MVP NOVA с AI-ассистентом «Борис» проходила итерации по фидбеку пользователей: https://nova-light-app.vercel.app/
— Интеграции: практика простых связок (Telegram → Google Sheets, логика CRM-карточек). WhatsApp / Instagram / Calendar в контуре JOL AI освою на стажировке по вашему стеку.

Самостоятельность: задачу довожу до результата без напоминаний; если вводных мало — задаю ключевые вопросы до старта, а не после провала дедлайна.

Формат стажировки и дальнейший переход в штат — ок. Готова к тестовому: промпт + мини-сценарий диалога / разбор слабого места агента.

Портфолио: https://portfolio-resume-alya-akbarova.vercel.app/
Резюме: https://portfolio-resume-alya-akbarova.vercel.app/resume-ai.pdf
Telegram: @Albinaa_Akbarova · Email: pilotalya@a-akbarova.ru

С уважением,
Альбина Акбарова
```
