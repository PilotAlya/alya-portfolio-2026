# Сопроводительное · ООО «Карьерный Компас» · Начинающий менеджер онлайн-поддержки (маркетплейс)

**Компания:** ООО «Карьерный Компас»  
**Роль:** начинающий менеджер онлайн-поддержки в цифровой маркетплейс (входящая линия)  
**Формат:** удалённо · 2/2 / 5/2 / от 4 ч · без продаж и холодных звонков  
**Оплата:** оклад + премии · 2 раза в месяц · бонус 10 000 ₽ за 1-й месяц  
**Оценка совпадения:** ~60% (задачи ок; **осторожно** с этапом «сторонние ресурсы»)

| Критерий | Комментарий |
|----------|-------------|
| Только входящие, без продаж/холoda | ✅ комфортный формат |
| Консультации по статусам / маркетплейсу | ✅ просто объяснять, грамотность |
| Проверка данных, заявки в системе | ✅ внимательность, QC |
| Опыт не нужен / обучение | ✅ |
| ПК + стабильный интернет | ✅ |
| Телефонная линия (голос) | ⚠️ штатного КЦ нет — наращу на обучении |
| Гибкий график, совмещение с учёбой | ✅ Нетология вне смены |
| «Действия на сторонних ресурсах» после отклика | ⚠️ проверить юрлицо; не вводить оплаты/коды «для оформления» вслепую |

> **Вердикт по отклику:** письмо можно отправить. До любых анкет на сторонних сайтах: уточнить название площадки, зачем данные и что **не** просят (оплата обучения, «залог», коды из SMS банкам).
