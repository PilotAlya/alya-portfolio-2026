```

Почему роль:
Подходит формат только входящих текстовых обращений: помочь в чате по инструкциям, зафиксировать данные, при необходимости передать коллегам и заметить сбой сервиса — без продаж и без звонков. Что приношу:

— Грамотная переписка, спокойный тон, без воды.
— Внимательность: данные по обращению вношу аккуратно; типовые ошибки сервиса фиксирую понятно для профильных специалистов.
— Дисциплина смены и работа строго по внутренним инструкциям.
— Ноутбук и стабильный интернет (Лысьва, Пермский край).
```
