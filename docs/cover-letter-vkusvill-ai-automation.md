## Текст сопроводительного

```
Здравствуйте, команда ВкусВилл!

Меня зовут Альбина Акбарова (Pilot Ali). Откликаюсь на вакансию специалиста по AI-автоматизации бизнес-процессов.

Мне близка ваша постановка: важнее скорость и умение работать с ИИ как с инструментом, чем «классическая» разработка с нуля. Так я и собираю рабочие решения — вайб-кодинг: промпт → генерация → проверка → доработка до результата, которым можно пользоваться.

Почему ВкусВилл и эта роль:

Есть опыт в ритейле и понимание, как больно, когда учёт, заказ и данные живут в разрозненных таблицах. Хочу разбирать текущую логику прогноза/автозаказа (в т.ч. Excel/VBA), воспроизводить её в более гибких AI-инструментах и итеративно доводить по фидбеку бизнеса — без лишнего «инженерного театра».

Что уже умею под ваши задачи:

— Вайб-кодинг: Cursor, OpenCode, Gemini, ChatGPT (Copilot/Claude подключаю по задаче). Собираю рабочие MVP и автоматизации не «с чистого листа руками», а через AI + жёсткую проверку результата.
  Портфолио: https://portfolio-resume-alya-akbarova.vercel.app/

— NOVA Dashboard — мой MVP: сама спроектировала и собрала (React/TypeScript, сценарий AI-ассистента «Борис»). Прототип → тесты с пользователями → 12+ замечаний → переработка в NOVA Light (3/3: стало понятнее).
  Live: https://nova-light-app.vercel.app/
  Презентация: https://alya-nova-2026.vercel.app/

— Excel/таблицы как источник требований: разбирала и воспроизводила логику сверок и расчётов в более удобных инструментах.
  • Legacy (ритейл, NDA): Price Checker и Data Validator — сверка с 10–20 минут до секунд; автоматизация рутины на участке.
  • Python + выгрузки: B2B-аудит CSV — нашла ошибки в логике оттока 72.7% → 63.6%, собрала dashboard: https://client-retention-dashboard.vercel.app/
  • LLM + Excel: пайплайн поиска/фильтрации → структурированная таблица: https://portfolio-resume-alya-akbarova.vercel.app/#case-studios

— Автоматизация процессов: Telegram → Google Sheets (lead capture) — https://portfolio-resume-alya-akbarova.vercel.app/#guides

— Работа с бизнесом: умею задавать вопросы «что считаем / какое правило заказа / что считается ошибкой», фиксировать критерии и не сдавать сырой AI-вывод.

Честно:
Прямого инструмента «прогноз спроса / автозаказ» в проде не делала. Зато умею быстро разобрать, что считает текущий Excel/VBA, перенести логику в новый прототип и довести итерациями. SQL и API — на уровне плюса из вакансии (Python/API уже использую; SQL наращиваю).

По формату: в вакансии указан офис. Сейчас живу в Лысьве; готова обсудить формат присутствия и возможность релокации по мере роста — важно заранее совпасть по ожиданиям.

Резюме: https://portfolio-resume-alya-akbarova.vercel.app/resume-ai.pdf

Буду рада созвону или тестовому: разобрать фрагмент логики заказа/прогноза из таблицы и набросать прототип на вайб-кодинге.

С уважением,
Альбина Акбарова
pilotalya@a-akbarova.ru · Telegram: @Albinaa_Akbarova
```
