# Сопроводительное · ИП Сотников · Копирайтер в онлайн-школу (хобби / сыроварение)

**Наниматель:** ИП Сотников Алексей Сергеевич (онлайн-школа хобби: сыры, молочка, гастрономия)  
**Роль:** копирайтер (email, чат-боты, автоворонки, прогревы, запуски)  
**Оценка совпадения:** ~42% (stretch)

| Критерий | Комментарий |
|----------|-------------|
| Опыт копирайтера в онлайн-школах **от 2 лет** | ❌ нет — критичный разрыв |
| Автоворонки, запуски, прогревы | ❌ прямого опыта нет |
| Продающие письма / адаптация под боты | ⚠️ есть ясный текст и гайды; продающий edtech-копирайт — нет |
| Tone of Voice, дедлайны, самостоятельность | ✅ |
| Погружение в новую тему | ✅ |
| CJM / воронки (плюс) | ⚠️ понимаю логику на базовом уровне |
| Ниша образования / хобби / кулинария (плюс) | ⚠️ образование — учёба в Нетологии; кулинария/сыры — новая тема |
| Удалёнка 5/2 | ✅ |

> **Вердикт:** по формальным требованиям вакансия слабая. Письмо честное — без «2 года в GetCourse». Имеет смысл откликаться только если готовы взять сильного «смежника» (ясный текст + дисциплина) и доучить воронки; иначе лучше не тратить слот.
