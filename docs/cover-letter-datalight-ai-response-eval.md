# Сопроводительное · Data Light · Оценка качества ответов нейросети

**Компания:** Data Light  
**Роль:** исполнитель по оценке качества текстовых ответов нейросети  
**Оценка совпадения:** ~88%

| Критерий | Комментарий |
|----------|-------------|
| Анализ запрос ↔ ответ нейросети | ✅ AI product evaluation |
| Оценка по критериям качества | ✅ Pass/Fail, чек-листы |
| Неточности, противоречия, лишнее / недостоверное | ✅ близко к QA / content check |
| Различная тематика | ✅ быстро вхожу по инструкции |
| Русский язык | ✅ |
| Логика, внимательность, решения в рамках критериев | ✅ |
| Опыт оценки / обработки текста (плюс) | ✅ |
| ГПХ самозанятый/ИП, удалёнка | ✅ |
| 4–6 часов в день | ⚠️ могу выделять блоки; объём согласую после онбординга |
| Онбординг ~5 дней (инструкция + экзамен) | ✅ готова |

## Текст сопроводительного

```
Здравствуйте, команда Data Light!

Меня зовут Альбина Акбарова (на проектах подписываюсь как Аля). Откликаюсь на вакансию исполнителя по оценке качества ответов нейросети.

Почему откликаюсь:
Мне близка работа «запрос → ответ модели → вердикт по критериям»: найти неточности, противоречия, лишнее или недостоверное и зафиксировать оценку строго по ТЗ. Это пересекается с моим опытом AI product evaluation и QA — без «на глаз», с опорой на правила.

Что релевантно:

— Оценка качества текстовых ответов: привыкла проверять вывод ИИ по чек-листу (соответствует / нет, замечания), а не принимать формулировки как данность.
— Внимательность к деталям: нахожу расхождения, логические дыры и лишнюю информацию; спорное отмечаю, а не решаю наугад.
— Разные тематики: спокойно вхожу в новые предметные области через инструкцию и примеры; держу фокус на критериях проекта, а не на личном мнении.
— Русский язык и логика: грамотная письменная речь; умею применять правила в неоднозначных ситуациях в рамках заданных критериев.
— Плюс из вакансии: опыт обработки и оценки текстовой информации (QA-отчёты, продуктовые проверки, работа с AI-инструментами с обязательной самопроверкой).

Формат: удалённо, ГПХ (самозанятость / ИП), оплата за фактически выполненное задание — подходит. Периоды работы выбираю сама; ориентир 4–6 часов в день понятен — готова выделять стабильные блоки времени, точный объём согласую после онбординга. Готова к подключению (~5 дней): регистрация, изучение ТЗ, обучение и экзамен.

Портфолио: https://portfolio-resume-alya-akbarova.vercel.app/
Резюме: https://portfolio-resume-alya-akbarova.vercel.app/resume-ai.pdf

С уважением,
Альбина Акбарова
pilotalya@a-akbarova.ru · Telegram: @Albinaa_Akbarova
```
