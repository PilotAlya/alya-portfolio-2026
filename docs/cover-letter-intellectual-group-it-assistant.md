## Текст сопроводительного

```
Здравствуйте, команда «Интеллектуал Групп»!

Меня зовут Альбина Акбарова (на проектах подписываюсь как Аля). Откликаюсь на вакансию ассистента в IT.

Мне подходит формат: только рабочие задачи по проекту, удалённо со своего места, без личных поручений. Главное для меня на такой роли — понять задачу до старта, задать ключевые вопросы и сдать результат быстро и аккуратно с первого раза, а не «переделывать после».

Что закрою:

— Google Docs / Sheets / Forms: веду таблицы и документы, собираю формы, обновляю статусы, готовлю понятные сводки.
— Саппорт клиентов/учеников: отвечаю по делу, спокойно и грамотно; если ответа нет в базе — фиксирую вопрос и эскалирую, не выдумываю.
— Системность: дроблю поручение на шаги, сверяю критерий «готово», держу порядок в файлах и статусах.
— Связь: в рабочее время на месте для переписок и звонков; работаю с ноутбука (не с телефона).
— VPN / интернет: стабильный доступ есть, с VPN работала; компенсацию VPN и Telegram Premium от компании принимаю — ок.

Честно: штатного опыта линии поддержки «годы в ТП» у меня нет. Зато есть привычка к регламентам, внимательность к деталям (QA-бэкграунд) и дисциплина уточнять вводные до выполнения — это как раз то, что вы ставите главным в позиции.
```

## Если спросят отдельно

**Почему без личных поручений — плюс**
```
Как раз ищу роль, где весь фокус на рабочем проекте: таблицы, статусы, саппорт, поручения команды. Бытовые задачи (отели, билеты, химчистка) не интересуют — откликаюсь осознанно на ваш формат.
```

**Как уточняете задачу**
```
До старта фиксирую: цель, критерий «готово», дедлайн, где взять данные, куда сдать, что делать при спорном случае. Если чего-то нет — один короткий список вопросов, затем выполнение без переделок «с нуля».
```

**Зарплата / график** (в вакансии вилки и часов нет)
```
График и вилку готова обсудить на собеседовании. Важно: понятные рабочие часы «на связи» и критерии роста оплаты, о которых вы пишете.
```
