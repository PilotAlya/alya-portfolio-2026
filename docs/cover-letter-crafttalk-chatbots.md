Почему CraftTalk:
Интересна прикладная работа на стыке диалогов, интеграций и качества: собрать сценарий в платформе, связать с системами заказчика через API и не выпустить логику со сбоями. Мне близка дисциплина «сначала проверить цепочку, потом запускать» — бэкграунд QA + ежедневная работа с LLM.

Что умею по обязанностям:

— Сценарии и логика диалогов: проектирую понятные ветки «вопрос пользователя → шаг → условие → ответ / эскалация». Умею раскладывать поведение в блок-схему и проверять краевые случаи (пустой ввод, повтор, уход с темы, ошибка интеграции).
— Интеграции и API: пишу простые скрипты на Python, работаю с REST, JSON, понимаю HTTP GET/POST и webhook-уведомления. Пример автоматизации: Telegram → Google Sheets (lead capture); пайплайны данных с LLM → Excel.
  Портфолио: https://portfolio-resume-alya-akbarova.vercel.app/
— Тестирование и стабильность: скрупулёзно прогоняю сценарии, фиксирую сбои в логике, не «надеюсь, что сработает». Привычка Pass/Fail и воспроизводимых шагов.
— Самостоятельность: разбираюсь в документации к API, уточняю неочевидное, спокойно разбираю ошибки и «падения».

Стек рядом с вакансией:
Python (скрипты), JavaScript/TypeScript (веб/MVP), Cursor / Gemini / ChatGPT, Git, Vercel. Есть опыт сборки MVP с AI-ассистентом (NOVA): https://nova-light-app.vercel.app/
