## 17. Тестовое: промпт + пост для соцсетей *

**Тема:** как ИИ меняет малый бизнес (ритейл / учёт) — близко к реальному опыту.

### (1) Промпт

```
Роль: ты — редактор коротких постов для владельцев малого бизнеса в России (розница, услуги, 1–15 сотрудников). Пишешь просто, без корпоративного пафоса и без «революции ИИ».

Задача: напиши пост в соцсети на тему «Как ИИ меняет малый бизнес».

Ограничения:
— 5–7 строк, каждая строка — отдельная мысль;
— язык: русский;
— без хештегов, без списков с маркерами, без капса;
— максимум 1 эмодзи во всём тексте (можно без эмодзи);
— не обещай «заменит сотрудников» и не продавай конкретный сервис;
— один конкретный рабочий пример (учёт / сверка / переписка / отчёты), не абстракция.

Структура:
1) хук — знакомая боль (время, ошибки, рутина);
2) что меняется с ИИ на практике (1 пример);
3) условие, без которого ИИ бесполезен (проверка человеком / правило);
4) маленький следующий шаг для читателя.

Критерий готовности: пост можно опубликовать как есть; после прочтения понятно и «что делать», и «где ИИ не справится сам».

Верни только текст поста, без пояснений.
```

### (2) Результат

```
Вечером после смены сверка цен и остатков до сих пор отнимает час — хотя продажи уже закрыты.
ИИ это меняет так: выгрузка → проверка расхождений → таблица за пару минут, а не вручную построчно.
Это не «робот вместо продавца», а меньше копипаста и глупых ошибок в цифрах.
Работает, только если вы сами задали правило: что считать верным и что делать, если цифры не сошлись.
Иначе модель просто быстрее разнесёт путаницу.
Возьмите одну ежедневную рутину, засеките время — и сравните «до» и «после» на одной задаче.
```
`
