### 2. Каковы основные различия в требованиях к аннотации данных для задач обнаружения объектов и семантической сегментации?

```
Обнаружение объектов (object detection) и семантическая сегментация решают разные задачи, поэтому и требования к разметке разные.

1) Единица разметки
— Detection: объект целиком задаётся ограничивающей рамкой (bounding box, иногда ориентированный box) + класс объекта.
— Semantic segmentation: класс назначается каждому пикселю (или полигону/маске с точной границей), а не «коробке» вокруг объекта.

2) Разделение экземпляров
— Detection: каждый экземпляр объекта размечается отдельно (две машины = две рамки), даже если класс один.
— Semantic segmentation: экземпляры одного класса обычно не разделяются — все пиксели класса «машина» относятся к одной категории; важно покрыть область класса, а не посчитать объекты.

3) Границы и фон
— Detection: критичны корректный охват объекта рамкой (не обрезать, не захватывать лишнее) и верный класс; фон как отдельный класс обычно не рисуют.
— Semantic segmentation: критична точность границ на уровне пикселей; фон чаще всего тоже класс и должен быть размечен согласованно по всей сцене.

4) Типичные ошибки, на которые смотрят в QC
— Detection: сдвиг/размер box, пропуск объекта, дубли, неверный класс, box «по воздуху».
— Segmentation: дыры в маске, выход за контур, перепутаны классы на границе, незакрытый фон, «лесенка»/грубые края там, где нужна точность.

5) Трудоёмкость
Семантическая сегментация обычно дольше и требовательнее к аккуратности контура; detection быстрее по объёму кадров, но важна полнота по всем целевым объектам на кадре.

(Если нужно — на тесте покажу на практике в вашем инструменте разметки.)
```
