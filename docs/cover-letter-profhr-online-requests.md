# Сопроводительное · ProfixHR · Специалист поддержки онлайн-заявок

**Компания:** ProfixHR  
**Роль:** специалист поддержки онлайн-заявок (входящие звонки, ввод в CRM, проверка данных)  
**Формат:** удалённо · 2/2 / 5/2 / частичная · смены утро–ночь (+20% ночь)  
**Опыт:** не обязателен · без продаж  
**Оценка совпадения:** ~72%

| Критерий | Комментарий |
|----------|-------------|
| Только поддержка по шаблонам, без продаж | ✅ |
| Входящие + ввод в CRM + проверка данных | ✅ аккуратность |
| Опыт не обязателен | ✅ |
| ПК + интернет | ✅ |
| Гибкий график / неполный день | ✅ |
| «Действия на сторонних ресурсах» после отклика | ⚠️ уточнить площадку; не платить «за оформление» |

## Текст сопроводительного

```
Здравствуйте, команда ProfixHR!

Меня зовут Альбина Акбарова (на проектах подписываюсь как Аля). Откликаюсь на вакансию специалиста поддержки онлайн-заявок (входящие обращения / звонки, ввод в CRM, проверка данных — без продаж).

Почему роль:
Подходит удалённая поддержка по готовым шаблонам: принять входящее, помочь клиенту и аккуратно внести данные в систему — без поиска клиентов и без продаж. Опыт не обязателен, всему обучаете — готова быстро войти по вашим инструкциям.

Что приношу:

— Грамотная речь (чат/почта уверенно; голос наращу на обучении), спокойный тон.
— Внимательность: проверю данные до сохранения в CRM, без «примерно».
— Усидчивость на потоке однотипных заявок и дисциплина смены.
— Рабочее место: ноутбук и стабильный интернет (Лысьва, Пермский край).
— График: 2/2 или 5/2, частичная занятость и смены утро/день/вечер/ночь (+20%) — обсуждаю под вашу линию.

Условия: оклад + премии или почасовая, ТК / ГПХ / самозанятость — ок. Готова к следующим шагам на ваших HR-ресурсах; перед заполнением сторонних форм попрошу коротко, что именно нужно и зачем.

Резюме: https://portfolio-resume-alya-akbarova.vercel.app/resume-ai.pdf
Telegram: @Albinaa_Akbarova · Email: pilotalya@a-akbarova.ru

С уважением,
Альбина Акбарова
```
