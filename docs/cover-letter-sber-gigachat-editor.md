## Текст сопроводительного

```
Здравствуйте, команда GigaChat / Сбер!

Меня зовут Альбина Акбарова (на проектах подписываюсь как Аля). Откликаюсь на вакансию редактора текстов для обучения нейросетей (AI-тренер).

Почему эта роль:
Мне близка работа «наставника» для модели: не просто красивый текст, а эталон, по которому видно, где ответ слабый, где логика ломается и как сформулировать лучше. Ежедневно работаю с LLM и не принимаю вывод «как есть» — проверяю факты, ясность и полезность.

Что буду делать на практике (уже делала в смежном формате):

— Создавать и редактировать тексты: пишу ясно, структурно, без канцелярита; довожу формулировки до понятного эталона (гайды, инструкции, упаковка кейсов).
  Портфолио: https://portfolio-resume-alya-akbarova.vercel.app/

— Анализировать ответы модели: находить фактические ошибки, дыры в логике, лишнее и недосказанное; фиксировать замечания так, чтобы их можно было использовать в дообучении/правках.
  Пример близкой задачи — оценка сценариев «Яндекс с Алисой» (Pass/Fail, Expected/Actual, severity):
  https://portfolio-resume-alya-akbarova.vercel.app/yandex-alice-qa-report.pdf

— Сценарии диалогов и тестовые задания: привыкла раскладывать поведение на шаги и критерии приёмки — это прямой навык для прогонов GigaChat.

— Фактчек и источники: на B2B-кейсе нашла ошибки в расчётах оттока (72,7% → 63,6%), сверка с исходными данными:
  https://client-retention-dashboard.vercel.app/

— Фидбэк разработчикам: пишу воспроизводимые замечания, без воды.

Плюсы из вакансии:
Опыт с LLM (ChatGPT, Gemini, Cursor и аналоги), проектирование промптов под задачу, Markdown и JSON на практике (документация, структуры данных, vibe-coding). GigaChat готова освоить в вашем контуре оценки.

Честно об образовании и профиле:
Классического высшего лингвистического / журналистского / переводоведческого нет. СПО — «Дизайн (по отраслям)», красный диплом; сейчас — «Системный аналитик» в Нетологии (дистанционно). Опыт с текстами — через редактуру, техдок/гайды, QA-отчёты и AI evaluation, а не через 5 лет копирайтинга в редакции. Если ВО по лингвистике — жёсткий фильтр, могу не пройти; если важнее качество эталонов и работа с LLM — готова показать уровень на тестовом.

Формат: удалённо — подходит.

Резюме: https://portfolio-resume-alya-akbarova.vercel.app/resume-ai.pdf
Telegram: @Albinaa_Akbarova · Email: pilotalya@a-akbarova.ru

С уважением,
Альбина Акбарова
```
