# Сопроводительное · ООО ЛУИС+ · AI-инженер

**Компания:** ЛУИС+ (системы безопасности, внутренние AI-инструменты)  
**Роль:** AI-инженер (прикладные AI-сценарии: прототип → регулярное использование)  
**Оценка совпадения:** ~68%

| Критерий | Комментарий |
|----------|-------------|
| Прикладные LLM-решения / ассистенты | ✅ NOVA + сценарий «Борис»; vibe-coding цикл до деплоя |
| Web-интерфейсы (React и аналоги) | ✅ NOVA, портфолио, CRM Lead Card |
| Python, API, данные | ✅ студии→Excel, B2B CSV/Pandas, парсеры |
| Автоматизация процессов | ✅ Telegram→Sheets, Legacy-скрипты |
| Evaluation / критерии приёмки | ✅ UX-тесты NOVA, Pass/Fail, не «промпт и забыл» |
| Документация и обучение пользователей | ✅ гайды, презентация NOVA, мануалы |
| Dify / n8n / Flowise / LangChain | ⚠️ не daily driver — готова быстро войти по вашему стеку |
| RAG / embeddings / vector search | ⚠️ понимаю контур и риски; прод-RAG в проде не строила — не завышаю |
| SQL / Docker / эксплуатация | ⚠️ SQL — учусь (Нетология SA); Docker/логи — базово, наращу |
| Домен СБ / электрика | ⚠️ новый — бизнесовую задачу разберу через процесс и данные |

> Сильная сторона для вакансии: **бизнес-задача → MVP → проверка пользы → доработка → чтобы реально пользовались**. Слабее — готовый опыт именно на Dify/n8n/RAG-платформе; это честно обозначить и закрыть готовностью к стеку.

## Текст сопроводительного

```
Здравствуйте, команда ЛУИС+!

Меня зовут Альбина Акбарова (на проектах подписываюсь как Аля). Откликаюсь на вакансию AI-инженера.

Мне близка ваша постановка: не «настроить промпт», а собрать рабочий инструмент вокруг AI — данные, логика процесса, интерфейс, проверка качества, документация — и довести до регулярного использования. Так я и работаю: разбираю задачу → собираю MVP на AI-assisted стеке → проверяю руками → итерирую → документирую, чтобы другим было понятно, как пользоваться.

Почему ЛУИС+:

Интересен прикладной контур внутренних AI-инструментов в компании с реальными объектами и процессами (не демо «ради демо»). Хочу переводить бизнесовые сценарии подразделений в ассистентов, workflow и полуавтоматические сервисы, которые сотрудники используют стабильно и безопасно.

Что уже умею по задачам роли:

— AI-сценарии и ассистенты: NOVA Dashboard — мой MVP (React/TypeScript): заказы, склад, Kanban и сценарий AI-ассистента «Борис». Сама спроектировала и собрала через Cursor / OpenCode / Gemini; 2 цикла UX-тестов, 12+ замечаний, переработка в NOVA Light (3/3 — стало понятнее).
  Live: https://nova-light-app.vercel.app/
  Презентация: https://alya-nova-2026.vercel.app/

— Web-интерфейсы под AI/операции: портфолио-лендинг и внутренние мини-сервисы на React (в т.ч. CRM Lead Card).
  Портфолио: https://portfolio-resume-alya-akbarova.vercel.app/
  CRM demo: https://alya-crm-lead-card.vercel.app/

— Данные и интеграции-скрипты на Python: очистка/структурирование выгрузок, API/LLM-фильтры, Excel/CSV.
  Пример: поиск студий → Gemini-классификация → Excel: https://portfolio-resume-alya-akbarova.vercel.app/#case-studios
  B2B-аудит данных: отток 72.7% → 63.6% + dashboard: https://client-retention-dashboard.vercel.app/

— Автоматизация процессов: Telegram → Google Sheets (lead capture) — гайд и сценарий расширения: https://portfolio-resume-alya-akbarova.vercel.app/#guides

— Качество и «человек в контуре»: не отпускаю AI-вывод вслепую. Фиксирую критерии, разбираю ошибки, делаю evaluation на уровне сценариев/Pass-Fail (опыт QA + AI product evaluation). Для внутренних инструментов это критично: проверка, подтверждение, понятные ограничения.

— Документация и онбординг: инструкции без «технического шума», презентации, гайды — чтобы сотрудники могли пользоваться без постоянного присутствия инженера.

Честно о пробелах и как закрываю:

— Dify, n8n, Flowise, LangChain / LlamaIndex в ежедневной работе пока не основной стек. Понимаю класс задач (workflow, агенты, оркестрация LLM) — готова быстро перенести навык vibe-coding и интеграций на ваш контур Dify + n8n.
— Прод-RAG (embeddings, chunking, vector search, reranking) глубоко в бою не строила — концепции и риски retrieval понимаю, не завышаю опыт. Готова собирать и тестировать RAG-контуры по вашим стандартам качества и безопасности данных.
— SQL / Docker / мониторинг — на уровне уверенного junior+: наращиваю (в т.ч. учёба на системного аналитика в Нетологии); для эксплуатационного контура опираюсь на аккуратность, env, логирование ошибок и критерии приёмки.
```
