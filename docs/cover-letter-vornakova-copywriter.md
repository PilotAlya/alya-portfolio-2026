```

Меня зовут Альбина Акбарова (на проектах подписываюсь как Аля). Откликаюсь на вакансию копирайтера.

Почему откликаюсь:
Интересен вход в копирайтинг с наставником: короткие тексты по ТЗ, вычитка и аккуратная сдача контент-менеджеру. Формат удалёнки и гибкого графика удобно совмещать с учёбой. Готова учиться на ваших задачах и ToV, а не «писать как получится».

Что уже умею:

— Грамотный письменный русский: пишу ясно, без канцелярита; вычитываю свои и чужие тексты на опечатки, стиль и смысл.
— Тексты по заданию: гайды, анонсы/описания, короткие формулировки для лендинга и кейсов — умею держаться брифа и дедлайна.
  Портфолио: https://portfolio-resume-alya-akbarova.vercel.app/
— Поиск и систематизация: собираю информацию по теме, раскладываю по пунктам, отдаю структурировано.
— Внимательность: бэкграунд QA — не пропускаю мелочи и не сдаю «на глаз».
— Docs / Word / Google Docs — уверенно.

Честно: отдельного опыта SMM-копирайтера в PR/рекламе мало — но вакансия как раз для начинающего с обучением. Быстро подстроюсь под ваш стиль постов и правила согласования.
```
