# Сопроводительное · ООО «Б2Б ФРЕНДС» · Оформитель онлайн-заявок

**Компания:** ООО «Б2Б ФРЕНДС»  
**Роль в названии:** оформитель онлайн-заявок  
**По факту обязанностей:** холодные звонки по готовой базе в «Скорозвон» + скрипт  
**Формат:** удалённо · ТК РФ · 5/2 · 8:00–17:00 или 9:00–18:00 МСК  
**Оплата:** фикс + мотивация · 2 раза в месяц · обучение 1–3 дня  
**Оценка совпадения:** ~40% (**осторожно** — ядро роли = холодные звонки)

| Критерий | Комментарий |
|----------|-------------|
| Грамотная речь, ПК, гарнитура, тишина, Wi‑Fi ≥50 | ✅ |
| Готовый скрипт и база | ✅ снижает порог входа |
| Холодные звонки | ⚠️ слабое место профиля / предпочтений |
| Продажи / интерес к обзвону | ⚠️ не core |
| Удалёнка, ТК, наставник | ✅ |

> **Вердикт:** если не хотите холодные звонки — **не откликаться** (название «оформитель заявок» мягче, чем суть). Ниже — честный текст, если сознательно готовы к обзвону.
