## Если спросят отдельно

**CRM / аналитика**
```
Работала с логикой CRM-карточек и статусов на своих контурах (Lead Card, операционный MVP NOVA) и с аналитическими сводками/дашбордами. Боевую CRM агентства (Bitrix24 / amoCRM / ваша система) в роли ОКК не вела — разберу поля воронки, обязательные этапы и правила заполнения по вашему регламенту в первые дни.
```

**Пример отчёта / вывода**
```
Формат, к которому привыкла: факт (что сломалось / какая метрика) → масштаб (сколько кейсов / какой этап) → гипотеза причины → рекомендация следующего шага. Пример мышления: аудит оттока 72,7% → 63,6% после пересчёта логики + dashboard для руководства.
```

**Зарплата**
```
Вилку готова обсудить на собеседовании после понимания объёма: число менеджеров, частота отчётов, глубина воронки. Ориентир для устойчивой полной удалённой занятости — от 50 000 ₽ на руки, точную цифру согласуем по зоне ответственности.
```
> Цифру «от 50к» поправь под себя перед отправкой, если спросит рекрутер; в основное письмо вилку не ставь.
