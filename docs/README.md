## Как адаптировать письмо за 5 минут

1. Открой **cover-letter-ai-native-engineer.md** (или role-specific файл).
2. Замени `[Компания / продукт / задача]` — 1–2 предложения из вакансии.
3. Выбери 2–3 кейса из блока «Арсенал» — не перечисляй всё.
4. Для QA/SA вакансий — добавь background-блок (Алиса, Browser, B2B audit) из templates.
5. Проверь: кейсы названы **проектами**, не «тестовым заданием».
