# Сопроводительное · ОсОО «Барельеф» · Технический контент-менеджер / AI-редактор

**Компания:** ОсОО «Барельеф» (металлоконструкции: производство и монтаж)  
**Роль:** технический контент-менеджер / AI-редактор (каталог сайта)  
**Формат:** удалённо · 5/2 · оклад 100 000 ₽ + KPI  
**Оценка совпадения:** ~48% (**stretch** — middle+ контент и ГОСТ/СП по металлоконструкциям слабее)

| Критерий | Комментарий |
|----------|-------------|
| Middle+ контент-менеджер | ❌ штатного middle+ нет — риск фильтра |
| Русский + структура | ✅ гайды, лендинг, упаковка кейсов |
| Самостоятельный ресерч незнакомых тем | ✅ |
| AI (Codex, Claude, ChatGPT…) | ⚠️ ChatGPT/Gemini/Cursor daily; Claude по задаче; Codex не daily |
| CMS | ⚠️ классический WP/Bitrix как контент-менеджер — мало; страницы собирала через код/деплой + контент |
| Таблицы, графика, Figma/Canva | ✅ таблицы; Canva/Gamma; Figma — базово; дизайн-бэкграунд |
| Страница целиком: ресерч → публикация | ⚠️ цикл понятен; каталог в проде CMS не вела |
| Строительная тематика (плюс) | ⚠️ дизайн, ММК/музей по ТЗ; ГОСТ/СНиП по металлоконструкциям — наращу |
| Оклад 100к + KPI | ⚠️ под middle+; отклик только если готовы к честному stretch |

> **Вердикт:** слабый формальный fit. Письмо честное + примеры работ + стек AI/CMS (как просят). Имеет смысл, если готовы взять смежника (дизайн + AI-редактура + ресерч) и доучить каталог/ГОСТы.

Опыта контент-менеджера уровня middle+ в штате у меня нет — и опыта ведения каталога металлоконструкций по ГОСТ/СП/СНиП тоже нет. Откликаюсь, потому что близки ваш цикл «ресерч → простой язык → таблицы/визуал → публикация» и ежедневная работа с AI под самопроверкой. Если нужен готовый middle+ с каталогом в стройке — могу не пройти фильтр. Если рассматриваете сильного смежника (структура + дизайн-взгляд + AI-редактура + ресерч) с погружением в металлоконструкции по вашей базе чертежей — ниже факты, примеры и стек.

Почему тема откликается:
Производство и монтаж металлоконструкций — техническая B2B-тема, где заказчику нужна ясность: размеры, вес, материал, применение, без «воды». Умею разбирать незнакомый предмет по источникам и объяснять просто. Дизайн-бэкграунд (СПО «Дизайн», красный диплом) + проекты с жёстким ТЗ (в т.ч. завод ММК, музей) помогают аккуратно оформлять таблицы, схемы и визуалы из чертежей/документов. ГОСТы и сортаменты по вашей номенклатуре освою на погружении — вы как раз предлагаете помощь в теме.

CMS и публикация:
