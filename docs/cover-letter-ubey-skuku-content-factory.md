### 3. Задача: лицо «плывёт» на 6 кадрах — консистентность и автоизмерение

```
Боевого пайплайна identity consistency не поднимала — отвечаю как задачу на мышление.

Как добивалась бы консистентности (слоями, не одним промптом):
1) Зафиксировать identity pack: 1–3 reference-кадра лица/персонажа + описание неизменных признаков (форма, причёска, возраст, отличительные черты).
2) Генерировать не «6 независимых кадров», а цепочку с якорем: один master identity → image-to-image / character-ref / IP-Adapter-подобные механизмы (в ComfyUI или API модели, где есть character consistency).
3) Держать одинаковый seed-политику / лок ключевых параметров и ограничивать drift позы/света между кадрами.
4) Если модель всё равно плывёт — face-lock / swap-слой на финале (осторожно с артефактами) или перегенерация только «падающих» кадров, а не всего ролика.
5) Для видео: короткие клипы от одного keyframe + склейка, а не длинный one-shot, где identity обычно разваливается.

Как автоматически измерять, что «поплыло»:
— детект лица на каждом кадре (bbox/landmarks);
— эмбеддинг лица (face embedding) и cosine similarity к reference; порог → fail;
— доп. эвристики: IoU/стабильность landmarks между соседними кадрами, резкий скачок расстояния эмбеддингов = drift;
— если similarity < порога на N кадрах из 6 — авто-брак агенту-критику + перегенерация только failed shots.
Рубрика «хорошо глазами зрителя» остаётся у контент-креатора; у инженера — стабильная метрика и гейт в конвейере.
```

### 4. Текущая связка: стартовый кадр → видео → липсинк на русском

```
Честно: это не мой ежедневный прод-стек. Ниже — как собрала бы тестовый контур на сегодняшнем рынке (с оговоркой, что финальный выбор — только после A/B прогонов на ваших референсах и бюджете API).

Вариант A (контроль и РФ-доступность):
1) Стартовый кадр: сильная image-модель с character/ref (или ComfyUI-workflow с IP-Adapter / face-ref) → locked hero frame.
2) Видео: Kling (image-to-video) — сильное движение/мимика; русский native audio у Kling обычно слабый/не целевой.
3) Голос RU: отдельный TTS (например ElevenLabs / аналог с нормальным русским).
4) Липсинк: отдельный шаг (HeyGen Lip Sync / Sync.so / Hedra-класс инструментов) поверх видео + RU-дорожки.

Вариант B (если доступен и нужен one-pass RU dialogue):
— стартовый кадр → Veo 3.1 (или близкий native-audio контур) для коротких говорящих кусков, где русский lip-sync встроеннее;
— всё равно гейт качества: WER/прослушивание + visual lip-score, не « credим модели».

Почему не «одна модель на всё»: на практике лучше разделить identity / motion / speech / lip-sync — иначе плывёт либо лицо, либо русский, либо оба. Матрицу моделей зафиксировала бы таблицей: шаг → модель → стоимость → fail-метрика → fallback.
```
