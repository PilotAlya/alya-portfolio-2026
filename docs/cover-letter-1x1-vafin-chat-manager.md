# Сопроводительное · 1x1 (ИП Вафин) · Менеджер по работе с клиентами в чате

**Наниматель:** ИП Вафин Булат Рамисович · платформа «1x1» (репетиторы / ЕГЭ)  
**Роль:** менеджер в чате (без звонков) — родители/ученики → подбор преподавателя → пробный урок  
**Формат:** удалённо · 3–5 ч/день · гибкий график · опыт не обязателен  
**Оплата:** оклад 5 000 ₽ в 1-й месяц при ИС + бонусы за показатели  
**Оценка совпадения:** ~70% по задачам · ⚠️ старт 5к очень скромный

| Критерий | Комментарий |
|----------|-------------|
| Только чат, без звонков | ✅ |
| Грамотно, быстро, по-человечески | ✅ |
| Подбор / запись на пробный / фиксация в CRM | ✅ по скрипту на обучении |
| 3–5 ч/день, ноутбук | ✅ |
| Опыт не обязателен | ✅ |
| Оклад 5 000 ₽ первый месяц | ⚠️ уточнить доход после ИС |

## Текст сопроводительного

```
Здравствуйте, Булат Рамисович / команда «1x1»!

Меня зовут Альбина Акбарова (на проектах подписываюсь как Аля). Откликаюсь на вакансию менеджера по работе с клиентами в чате (без звонков).

Почему роль:
Подходит формат связки «ученик/родитель ↔ преподаватель» только в переписке: быстро и грамотно ответить, уточнить запрос, помочь подобрать преподавателя, записать на пробный урок и аккуратно зафиксировать данные. Опыт не обязателен — готова к обучению и работе строго по вашим скриптам. Занятость 3–5 часов в день и удалёнка удобны (совмещаю с учёбой в Нетологии вне смены).

Что приношу:

— Грамотная письменная речь, спокойный человеческий тон, без воды и без давления.
— Дисциплина «на связи» в выбранные часы: отвечаю быстро, диалоги не бросаю.
— Внимательность к деталям в карточке клиента (запрос, слот, статус).
— Ноутбук и стабильный интернет есть (Лысьва, Пермский край).

Условия: удалёнка, гибкий график, бонусы за показатели — ок. Оклад 5 000 ₽ в первый месяц при прохождении испытательного срока — формат понятен; готова обсудить, как считается доход после ИС и какие KPI на бонусы.

С уважением,
Альбина Акбарова
```
