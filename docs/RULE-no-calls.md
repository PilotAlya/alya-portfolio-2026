# Правило отбора вакансий · звонки

**Статус:** обязательно с 17.08.2026  
**Для:** Альбина Акбарова (Аля)

## Правило

**Всё, что связано с тёплыми или холодными звонками — отсекаем. Не интересно. По умолчанию не пишем сопроводительные и не откликаемся.**

### Отсекать (skip), если в обязанностях есть:
- холодные звонки / обзвон базы / телесейлз / «Скорозвон» как ядро роли
- тёплые звонки / дожим по телефону / исходящие звонки клиентам как основной канал
- колл-центр с акцентом на голос (входящие+исходящие продажи)
- смешанные роли, где звонки — обязательная ежедневная нагрузка, а не редкое уточнение

### Можно рассматривать:
- только чат / почта / мессенджеры (без звонков)
- входящая поддержка **только текстом**
- роли, где голос эпизодический («при необходимости уточнить») — **спросить Алю**; по умолчанию лучше skip, если звонки в описании заметны

### Уже помеченные как skip / слабый приоритет из-за звонков:
- [Б2Б ФРЕНДС](./cover-letter-b2b-friends-cold-calls.md) — холодные звонки → **не откликаться**
- [ВШИИ · администратор](./skip-vshii-admin-warm-calls.md) — тёплые звонки по скрипту + обязательный опыт КЦ → **не откликаться**
- вакансии КЦ/«входящие+исходящие» с продажами — skip
- аккаунт в школе **только чат** — ок; если добавят обязательные звонки — skip

## Как отвечать агенту / себе
При новой вакансии первым экраном: «Есть ли тёплые/холодные звонки?»  
Если да → **skip** + коротко почему, без полного письма (если Аля явно не попросила исключение).
