# Ответ · Почему ищете работу? (аккаунт-менеджер в онлайн-школу)

**Контекст:** отклик аккаунт-менеджером в онлайн-школу  
**Тон:** коротко, по делу, без негатива про прошлое место

---

## Рекомендуемый ответ (копировать)

```
Ищу основную удалённую работу, где можно растить клиентский навык и работать с людьми по понятным процессам. Сейчас целевой трек — аккаунт-менеджер в онлайн-школе: вести учеников/родителей, держать сервис и доводить договорённости до результата. Хочу стабильную роль с обучением и ростом внутри команды, а не разовые подработки.
```

## Если спросят «почему уходите / меняете сферу»

```
В ритейле был сильный опыт по качеству и дисциплине, но хочу развиваться в клиентской работе онлайн-образования: ближе формат чата/сопровождения и понятный вклад в результат ученика.
```

> Не пиши плохо про текущего работодателя. Не выдумывай «уволили» / «конфликт».
