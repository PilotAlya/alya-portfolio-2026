# Ответ · Почему ищете работу? (аккаунт / EdTech / репетиторы)

**Контекст:** анкеты и 2-й этап тестирования (онлайн-школа, «твой репетитор», подбор преподавателя)  
**Тон:** коротко, по делу, без негатива про прошлое место

---

## Для «твой репетитор» (копировать)

```
Ищу основную удалённую работу в EdTech, где можно растить клиентский навык и работать с людьми по понятным процессам. Интересен формат сервиса вокруг обучения: помочь ученику или родителю с запросом, подобрать подходящего репетитора и довести договорённость до результата. Хочу стабильную роль с обучением и ростом внутри команды, а не разовые подработки.
```

