# Сопроводительное · Data Light · Специалист по поиску видеоконтента

**Компания:** Data Light  
**Роль:** поиск и отбор видео/каналов для обучения AI-моделей  
**Оценка совпадения:** ~76%

| Критерий | Комментарий |
|----------|-------------|
| Поиск по критериям / ТЗ | ✅ работа по инструкциям, чек-листы QA |
| Проверка соответствия требованиям | ✅ Pass/Fail, сверка «ожидание ↔ факт» |
| Отбор и структурирование | ✅ таблицы, статусы, аккуратная фиксация |
| Однотипный большой объём | ✅ усидчивость, сверки, разметка-логика |
| ПК / удалёнка / ГПХ самозанятый | ✅ |
| Опыт модерации / видео / разметки | ⚠️ прямого модерации видео мало; близко — QA + контент по критериям |
| Интерес к AI | ✅ vibe-coding / AI-проекты в портфолио |

> Рядом есть письмо про **проверку описаний видео**: [cover-letter-datalight.md](./cover-letter-datalight.md) — это другая роль.

## Текст сопроводительного

```
Здравствуйте, команда Data Light!

Меня зовут Альбина Акбарова (на проектах подписываюсь как Аля). Откликаюсь на вакансию специалиста по поиску видеоконтента.

Почему откликаюсь:
Задача понятная и системная: искать видео и каналы по заданным критериям, проверять соответствие ТЗ, отбирать и структурировать результат. Мне комфортно работать по инструкции, с большим объёмом однотипных задач и без «примерно подходит».

Что релевантно:

— Поиск и отбор по требованиям: умею держать в голове чек-лист критериев и не смешивать «похоже» с «соответствует».
— Проверка соответствия ТЗ: опыт QA и AI product evaluation — сценарий → факт → вердикт Pass/Fail, фиксация расхождений (кейсы Яндекса и продуктовые проверки — в портфолио).
— Структурирование: привычка вести статусы и результаты аккуратно в таблицах/списках, чтобы объём не превращался в хаос.
— Усидчивость и сроки: довожу однотипные задачи до закрытия, не пропускаю мелочи (бэкграунд контроля качества + принцип «1 мм»).
— Интерес к AI: собираю прикладные AI/vibe-coding проекты; понимаю, зачем качественные данные важны для обучения моделей.

Плюсы из вакансии: опыта модерации видео «в чистом виде» мало — зато сильна проверка по инструкции и аккуратный отбор. Готова быстро войти в вашу методику поиска на платформах.

Формат: полностью удалённо, ГПХ / самозанятость, проектная занятость от 4 часов — подходит. Ноутбук есть. Готова к обучению, поддержке и тестовому заданию.

Портфолио: https://portfolio-resume-alya-akbarova.vercel.app/
Резюме: https://portfolio-resume-alya-akbarova.vercel.app/resume-ai.pdf

С уважением,
Альбина Акбарова
pilotalya@a-akbarova.ru · Telegram: @Albinaa_Akbarova
```
