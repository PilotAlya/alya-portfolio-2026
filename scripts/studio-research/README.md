# Автоматизация research студий дизайна

Пайплайн для задачи «Бизнес-ассистент / Лид-менеджер»: поиск студий → таблица → ручная проверка.

## Быстрый старт (Python)

```bash
cd scripts/studio-research
pip install -r requirements.txt

# Проверенный seed (для импорта в Google Sheets)
python research_studios.py --seed --output output/studios_seed.csv

# Только Москва из seed
python research_studios.py --seed --city Москва --limit 3 --output output/moscow.csv

# Автопоиск через DuckDuckGo (кандидаты → нужна ручная проверка!)
python research_studios.py --search --city Пермь --limit 10 --output output/perm_search.csv
```

CSV импортируется в Google Sheets: **Файл → Импорт → Загрузить**.

## Схема автоматизации (n8n / Make)

```
┌─────────────┐     ┌──────────────┐     ┌─────────────┐     ┌──────────────┐
│  Триггер    │────▶│  Поиск       │────▶│  AI-фильтр  │────▶│ Google Sheets│
│  (расписание│     │  DDG / Serp  │     │  GPT/Claude │     │  новая строка│
│   или форма)│     │  + город     │     │  студия?    │     │              │
└─────────────┘     └──────────────┘     └─────────────┘     └──────────────┘
                                              │
                                              ▼
                                        ┌──────────────┐
                                        │ Telegram /   │
                                        │ Email: «N    │
                                        │ на проверку» │
                                        └──────────────┘
```

### n8n (бесплатный self-host или cloud)

1. **Schedule Trigger** — раз в день или по кнопке  
2. **HTTP Request** или **DuckDuckGo node** — запрос `студия дизайна интерьера {город} команда`  
3. **Code node** — убрать дубли URL  
4. **OpenAI / HTTP to OpenRouter** — промпт:

   ```
   URL: {{url}}, Title: {{title}}, Snippet: {{snippet}}
   Это студия дизайна интерьера с командой (не фрилансер-одиночка)?
   Верни JSON: { "is_studio": bool, "name": "", "founder": "", "reason_one_sentence": "" }
   ```

5. **IF** — `is_studio === true`  
6. **Google Sheets** — Append row  
7. **Telegram** — «Добавлено 5 кандидатов, проверь столбец „Статус“»

### Make (Integromat)

Тот же сценарий: **Google Sheets → Search → OpenAI → Filter → Google Sheets**.

## Что автоматизируется полностью, а что нет

| Этап | Авто | Комментарий |
|------|------|-------------|
| Поиск URL | ✅ | DDG, SerpAPI, Google CSE |
| Отбор «студия vs одиночка» | ⚠️ частично | AI + эвристики, финал — руками |
| Имя основателя | ⚠️ частично | Часто только с парсинга «О нас» |
| Переписка по скрипту | ⚠️ | Можно шаблоны, но не спам-бот |
| Трекинг статусов | ✅ | Google Sheets / Notion |
| Фоллоу-ап | ✅ | n8n по дате «нет ответа 3 дня» |
| Zoom в календарь | ✅ | Calendly + Sheets |
