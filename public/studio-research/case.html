Поиск дизайн-студий с AI-фильтрацией

Локальный Python-скрипт ищет студии по городу, читает тексты их сайтов и с помощью ИИ оставляет только команды — без фрилансеров-одиночек.

Python BeautifulSoup Gemini API Pandas / Excel Пермь · Екатеринбург

Как работает

1. ПоискНаходит сайты студий по запросу и городу
2. ПарсингСобирает текст с главной, «О нас» и «Команда»
3. AI-анализОпределяет: команда или фрилансер
4. ExcelВыгружает только релевантные студии

Результат

  1. Автоматический сбор лидов вместо ручного ресёрча
  2. Фильтрация «команда / одиночка» через LLM
  3. Готовая таблица с сайтами, основателями и доказательствами
  4. Проверено на Перми и Екатеринбурге
